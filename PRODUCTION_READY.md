## 📝 Data Flow

### How Data Works:

1. **User enters data** in the app
2. **App validates** the input
3. **Data sent to Supabase** via API
4. **Supabase stores** in database
5. **App receives confirmation**
6. **UI updates** with new data
7. **Data persists** across sessions

### Example: Adding a Worker

```
User fills form → Click "Save" → Data sent to Supabase → 
Worker saved in database → UI updates → 
Worker appears in list → Data persists
```
