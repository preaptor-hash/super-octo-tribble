## 🔧 Troubleshooting

### Issue: "Cannot connect to server"
**Solution:** The dev server is already running! Just open http://localhost:5173/

### Issue: "Page is blank"
**Solution:** 
1. Open browser console (F12)
2. Look for error messages (now visible!)
3. Check if Supabase credentials are correct in `.env`

### Issue: "Login fails"
**Solution:**
1. Verify Supabase credentials in `.env` file
2. Check browser console for error details
3. Ensure you have a user account in Supabase

### Issue: "Slow loading"
**Solution:**
- First load may take a few seconds (dependency optimization)
- Subsequent loads will be faster
- Session restore has 10s timeout (then redirects to login)
